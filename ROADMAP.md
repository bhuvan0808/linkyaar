# Roadmap

Live version with more detail: [linkyaar.com/roadmap](https://linkyaar.com/roadmap)

## Shipped ✅

- [x] Foundation: tooling, design tokens, Supabase, schema
- [x] Landing page (bold color-block design) at [linkyaar.com](https://linkyaar.com)
- [x] Email, magic-link, and Google authentication
- [x] Dashboard: links manager (drag-and-drop, scheduling, featured), appearance, settings
- [x] 27 themes + Theme Studio (custom wallpapers, fonts, button styles, colors, live preview)
- [x] Header layouts (Classic / Portrait / Minimal) and 6 font personalities
- [x] AI bio & headline writer (free, rate-limited, 4-provider free-tier chain)
- [x] Public creator pages with SEO + dynamic OG images + click/view tracking
- [x] Analytics: views, clicks, CTR, countries, sources, devices, top links
- [x] Audience: subscriber collection (CSV export) and moderated reviews
- [x] Email: welcome, notifications, weekly digests, branded auth emails (Resend)
- [x] Platform rate limiting (Upstash), analytics (PostHog), errors (Sentry)
- [x] Donations: UPI support page + Buy Me a Goddie
- [x] Custom domain, QR codes, GDPR export, account deletion

## Next 🔨

- [ ] Content embeds: YouTube, Spotify, and more
- [ ] Link thumbnails and custom icons

- [ ] Digital business cards (vCard download)
- [ ] Free digital downloads
- [ ] Pattern and image wallpapers in the Studio
