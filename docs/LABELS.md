# GitHub Labels

Standard label set for issues and PRs. Apply one `type:` and one `status:`
label to every issue.

## Type

| Label            | Color     | Use for                          |
| ---------------- | --------- | -------------------------------- |
| `type: bug`      | `#d73a4a` | Something broken                 |
| `type: feature`  | `#6e3aff` | New functionality                |
| `type: docs`     | `#0075ca` | Documentation only               |
| `type: design`   | `#c5a3ff` | Visual/UX work                   |
| `type: perf`     | `#fbca04` | Performance                      |
| `type: security` | `#b60205` | Security (see SECURITY.md first) |
| `type: chore`    | `#ededed` | Tooling, deps, CI                |

## Status

| Label                 | Color     | Meaning                     |
| --------------------- | --------- | --------------------------- |
| `status: triage`      | `#ededed` | Awaiting maintainer review  |
| `status: accepted`    | `#0e8a16` | Ready to be picked up       |
| `status: in progress` | `#1d76db` | Someone is actively working |
| `status: blocked`     | `#d93f0b` | Waiting on something else   |

## Community

| Label              | Color     | Meaning                          |
| ------------------ | --------- | -------------------------------- |
| `good first issue` | `#7057ff` | Scoped, mentored, newcomer-ready |
| `help wanted`      | `#008672` | Maintainers want contributions   |

Setup note: enable **GitHub Discussions** in repo settings (Settings →
General → Features) for questions and ideas, keeping Issues for actionable
work.
